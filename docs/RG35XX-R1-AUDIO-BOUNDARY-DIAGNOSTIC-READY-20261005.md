Date: 2026-10-05

## Reason

God of War JAR analysis proved that the commercial game contains real MIDI resources, that the game creates multiple standard MMAPI `Player` instances, and that the RG35XX platform extracts and loads the expected MIDI byte streams. The current physical failure remains audible continuity during gameplay, while programmatic `MIDI_LOAD` / `MIDI_PLAY` returns PASS.

No production runtime change is authorized by this diagnostic.

## Diagnostic scope

One generic, non-commercial MIDlet separates two remaining owner classes:

1. `A_COMPLEX_FORMAT1` — synthetic SMF format-1, 11 tracks, multiple channels/programs. This checks whether the SDL1_mixer boundary can audibly render a more complex MIDI than the simple P3 fixture.
2. `B_MULTI_PLAYER_LIFECYCLE` — BGM A -> stop -> one-shot B with a long silent tail -> stop -> restart A. This checks whether independent Java MMAPI `Player` state is incorrectly collapsed onto SDL_mixer's single global `Mix_Music` state.

The fixtures are generated by the build script and contain no commercial/game bytes.
