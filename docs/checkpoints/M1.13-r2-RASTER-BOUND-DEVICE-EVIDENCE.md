## Visual review correction
Initial visual review described apparent residual overlap around `SMALL ASCII`, `MIX`, `MEDIUM ASCII`, `RIGHT TOP`, and `BASELINE`.

A second direct inspection shows the repeated vertical feature occurs at the uppercase letter `I` in each of those locations:
- `ASCII`
- `MIX`
- `MEDIUM`
- `RIGHT`
- `BASELINE`

The same shape repeating exactly at `I` is consistent with the bitmap glyph design, not random overlap between adjacent glyphs. Therefore an `INTER_GLYPH_SPACING_ONLY` patch is NOT justified by this evidence and must not be applied speculatively.

r2 also preserves visible Vietnamese/Unicode, including mixed text and `Đấu`, with no CK-style all-glyph disappearance.
