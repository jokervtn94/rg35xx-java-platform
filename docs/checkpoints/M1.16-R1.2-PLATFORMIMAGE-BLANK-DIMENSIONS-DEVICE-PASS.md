# M1.16-r1.2 PlatformImage Blank Dimensions — DEVICE-PASS

Evidence date: 2026-09-17
Scope: headless blank `PlatformImage` dimension semantics only.
Full platform status: NOT STABLE.

## Preflight / symptom

M1.16-r1.1 Image→Sprite isolation failed before Sprite semantics could be evaluated. A blank mutable `Image.createImage(w,h)` had a headless `PlatformImage` with `canvas == null`, while upstream `getWidth()` / `getHeight()` dereferenced `canvas`.

Historical M1.9 evidence showed blank mutable images had previously worked. The minimal change was therefore restricted to restoring dimension access for the already-existing headless int[] backing path.

## Runtime delta

Patch: `miyoo-m1/m1_16/patch_platformimage_blank_dimensions_r12.py`

Only `PlatformImage.getWidth()` and `PlatformImage.getHeight()` receive a headless fallback:
- normal `canvas != null` path remains upstream behavior;
- when `rg35xx.headless.image.probe=true` and canvas is absent, return stored `rg35xxWidth` / `rg35xxHeight`;
- otherwise fail closed with `IllegalStateException`.

No Sprite, TiledLayer, renderer, audio, font, input, video or RMS implementation change.
