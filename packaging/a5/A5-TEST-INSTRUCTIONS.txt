RG35XX-AWEIGIT-R1 - A5 CORE INTEGRATION
========================================

Muc tieu
--------
Mot package duy nhat kiem Level-2 core integration tren RG35XX that:
resize 240x320 -> 640x480, resource stream, Image/transparency, PNG resource,
mutable/copy Image, font/text, Sprite 8 transforms, collision, TiledLayer,
LayerManager va RMS persistence qua 2 JamVM process A -> B.

Audio/media van HOLD.

Cai dat
-------
1. Extract All toan bo ZIP.
2. Cam SD RG35XX vao PC.
3. Double-click INSTALL-A5-RG35XX.cmd.
4. Chi nhap ky tu o dia, vi du H.
5. Neu [PASS], thao SD an toan va gan vao RG35XX.
